# NovaMart – Retail Sales Analysis & Performance Dashboard

**Shop Smart. Live Better.**

## 📊 Project Overview

This project focuses on analysing retail sales data for NovaMart, a fictional retail company, using Microsoft Excel.

The objective is to explore sales performance, identify top-performing products and categories, compare regional revenue, and understand monthly sales trends through an interactive-style dashboard.

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas and Functions
- Data Cleaning
- PivotTables
- PivotCharts
- Data Visualization

## 🔍 Analysis Performed

- Reviewed and prepared the retail sales dataset.
- Calculated total sales after discounts.
- Analysed total revenue, order count, quantity sold, and average order value.
- Compared revenue across products and categories.
- Evaluated sales performance across regions.
- Explored monthly sales trends.

## 💡 Key Insights

- **Top Product:** Smartphone – Rs. 4,963,750
- **Top Category:** Electronics – Rs. 9,622,000
- **Top Region:** Southern – Rs. 3,979,515
- **Best-performing Month:** January – Rs. 1,877,230
